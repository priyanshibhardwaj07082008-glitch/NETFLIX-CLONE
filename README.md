

# 🎬 Netflix Clone

A Netflix-inspired website built using **HTML and CSS** as a frontend development practice project.

## 📌 About the Project

The Netflix Clone is a beginner-friendly web development project inspired by Netflix's user interface. It focuses on creating a visually appealing webpage using HTML for structure and CSS for styling.

## ✨ Features

- 🎥 Netflix-inspired user interface
- 🎨 Custom styling using CSS
- 🖼️ Background image and visual elements
- 🧭 Navigation bar
- 💻 Beginner-friendly code

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling, layouts, and background images

## 📂 Project Structure

```text
NETFLIX-CLONE/
├── index.html
├── style1.css
├── logo.png
└── README.md
```

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/priyanshibhardwaj07082008-glitch/NETFLIX-CLONE.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.
